# Loomy 领取消息：报告真实到账，不再只看任务标称

新手任务面板的 8 项任务标称共 10000 积分，领取结果却直接把这个和当成战果打印出来。真机上出现过「消息说 +10000、余额看上去没动」的情况——不是没到账（`availableBalance` 9989 → 19987，余额窗口 5000 → 15000，确实 +10000），而是积分服务有几分钟的读缓存，而消息本身没有任何可供核对的数字。

- 领取前后各读一次可用积分（`/points/records` 的 `availableBalance`），消息里同时给出标称值与真实差值：`本次领取 8 项，任务标称 +10000 积分；可用积分 9989 → 19987（+10000）；已领过 0 项`。真机复核时补领一次（8 项全已完成）得到 `可用积分 19987 → 19987（+0）；已领过 8 项`，与余额窗口 15000 + 4987 对得上。
- 任一读取失败时退回只有标称值的写法，并明确标成「任务标称」，不再让一个未经核实的数字看起来像已确认结果。
- 单任务领取同样处理。
- 假网关现在会随领取调整余额，并支持"标记完成但不加分"的模式，两条路径各有一个单测钉住。
